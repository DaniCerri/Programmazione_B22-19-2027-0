# Primi algoritmi
## Che cos'è un algoritmo
L'algoritmo è una sequenza di istruzioni che porta al compimento di un'operazione. In altre parole un algoritmo è un elenco ordinato di operazioni **non ambigue** che porta al risultato desiderato. 

Nell'informatica il problema prende il nome di **input** e il risultato viene chiamato **output**.
In altre parole "input" è ciò che entra nell'algoritmo e "output" è ciò che ne esce.

### Esempi

2. Ricetta di un piatto o bevanda

## Caratteristiche degli algoritmi
Affinché un algoritmo sia **corretto** è necessario che abbia delle caratteristiche:
1. **Finitezza**: finisce sempre in un numero finito di passi
2. **Definitezza**: non deve contenere istruzioni ambigue
3. **Efficienza**: deve essere efficiente | Questa caratteristica infuirà molto poco nel percorso di quest'anno
4. **Generalità**: deve essere generale | Questa caratteristica sarà il centro di quest'anno: **noi vogliamo risolvere ogni problema del tipo che stiamo affrontando.**
Es: Se facciamo un algoritmo per calcolare la media di sette numeri diversi, questo deve riuscire a calcolarla con qualsiasi set di sette numeri. Quindi deve funzionare con [1, 2, 3, 4, 5, 6, 7] e [9, 8, 7, 6, 5, 4, 3]
